---
name: one-question-at-a-time
description: User prefers scoping interview questions asked one at a time, not in a batch
type: feedback
---

During scoping interviews, ask questions one at a time so the user can answer each individually.

**Why:** Batching many questions at once is overwhelming and harder to respond to.
**How to apply:** In any multi-question interaction (scoping, clarification, etc.), present one question, wait for the answer, then ask the next.
